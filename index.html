    How to get a YouTube API key

    my-tube reads channel data through the free YouTube Data API. You create a key in your own Google account, so the quota and the key stay yours. It takes about five minutes.

    1. Open the Google Cloud console and sign in with your Google account: console.cloud.google.com. Select a project from the top bar, or create one with New project.
    2. Enable the API. Go to APIs & Services → Library, search for YouTube Data API v3, open it, and click Enable.
    3. Create the key. Go to APIs & Services → Credentials, click Create credentials → API key, and copy the key that appears.
    4. Restrict the key (recommended). Click the key to edit it, then:
      • API restrictions: choose Restrict key and select only YouTube Data API v3.
      • Website restrictions: add https://<your-user>.github.io/*, for example https://etnt.github.io/*. Use the site address only, not the project path. For local testing, also add http://localhost:5173/*.
    5. Paste the key into the field above and click Save key. Changes to restrictions can take a few minutes to apply.

    If something fails

    • “Permission denied”: the API is not enabled, or YouTube Data API v3 is missing from the key’s API restrictions (step 2 or 4).
    • “not allowed on this site”: the website restriction does not match the address in your browser (step 4).
    • “Daily quota reached”: the quota resets at midnight Pacific time.

    The key is stored only in this browser. Google may show a banner about an OAuth consent screen; you can ignore it, because this app uses a plain API key.

    About my-tube

    my-tube is a personal dashboard for your favourite YouTube channels. Add the channels you follow and see how long ago each one last uploaded, along with the latest videos in one feed.

    • Dashboard: one card per channel, sorted by the most recent upload.
    • Videos: the merged feed of recent uploads, with NEW markers since your last visit.
    • Channels: add or remove channels, tag them (e.g. Science, History), and save your YouTube API key.

    It runs entirely in your browser and stores your data locally. Nothing is sent to a server except requests to the YouTube Data API, which uses your own API key.
